# Portfolio - Wilfried Melangi

Portfolio professionnel en ligne présentant mes projets, compétences et expériences en tant qu'Ingénieur Informatique spécialisé en développement web.

## 🚀 Fonctionnalités

- **Design moderne et épuré** : Interface minimaliste avec des animations fluides
- **Responsive** : Adaptation parfaite sur tous les appareils (mobile, tablette, desktop)
- **Projets dynamiques** : Intégration avec l'API GitHub pour afficher les projets en temps réel
- **Filtrage des projets** : Navigation facile entre les différentes catégories de projets
- **Formulaire de contact** : Interface de contact avec validation et notifications
- **Animations scroll** : Effets de révélation au défilement pour une expérience immersive
- **Navigation fluide** : Scroll smooth et menu de navigation fixe

## 🛠 Technologies utilisées

- **HTML5** : Structure sémantique moderne
- **CSS3** : Design avec animations et transitions avancées
- **JavaScript Vanilla** : Fonctionnalités interactives sans framework
- **GitHub API** : Récupération dynamique des projets
- **Font Awesome** : Icônes professionnelles
- **Google Fonts (Inter)** : Typographie moderne et lisible

## 📁 Structure du projet

```
portfolio/
├── index.html          # Page principale avec structure HTML5
├── styles.css          # Styles CSS avec design responsive
├── script.js           # Fonctionnalités JavaScript
└── README.md           # Documentation du projet
```

## 🎯 Sections du portfolio

1. **Accueil** : Hero section avec présentation et liens rapides
2. **À propos** : Biographie détaillée et informations de contact
3. **Compétences** : Grille interactive des compétences techniques
4. **Projets** : Gallery de projets avec filtrage et détails GitHub
5. **Expériences** : Timeline des expériences professionnelles
6. **Contact** : Formulaire de contact fonctionnel

## 🔄 Intégration GitHub

Le portfolio se connecte automatiquement à l'API GitHub pour :
- Récupérer les derniers projets
- Afficher les statistiques (stars, forks)
- Mettre à jour les descriptions
- Filtrer les projets archivés

## 📧 Formulaire de contact

Le formulaire inclut :
- Validation en temps réel
- Messages d'erreur personnalisés
- Indicateur de chargement
- Notifications de succès/erreur
- Reset automatique après envoi

## 🔧 Personnalisation

Pour personnaliser le portfolio :

1. **Modifier les informations personnelles** dans `index.html`
2. **Adapter les couleurs** dans `styles.css` (variables CSS)
3. **Mettre à jour les projets** dans `script.js`
4. **Changer le thème** en modifiant les variables CSS
